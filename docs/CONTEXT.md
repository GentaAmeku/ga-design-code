# G.A Design & Code

個人ポートフォリオサイト。白を基調とし、情報量よりシンプルさと綺麗さを優先する。

この文書はデザインと構造を語るための用語集で、仕様でも実装メモでもない。決定は [adr/](./adr/) に、見た目の定義は [design-system/](./design-system/) にある。

## 骨格

**セクション** (Section):
トップページを構成する画面単位。1スクロールにちょうど1つ収まる。
_避ける_: ブロック、ページ、エリア

**骨格** (skeleton):
幅・配置・高さの規則。具体的には `max-w-3xl` 一本の幅、中央寄せ、1スクロール1セクション。色や文字は含まない。
_避ける_: レイアウト、グリッド

**下層ページ**:
トップページ以外のページ。2026-08 時点で `/preview` のみ。骨格はトップページと共有しない。

## 文字

使う型は4つだけで、通しの大小スケールは持たない。

**大見出し** (display):
トップに一度だけ置くサイト名。`text-4xl md:text-5xl`。

**セクション見出し** (section heading):
各セクションの題。`text-3xl md:text-4xl`。
_避ける_: タイトル、h2

**リード** (lead):
セクション見出しの直下に置く一文の補足。`md:text-lg`、色は `muted-foreground`。
_避ける_: サブタイトル、説明文

**本文** (body):
段落。`text-lg leading-loose tracking-wide`。

## 色

**テーマ** (theme):
アクセント色の入れ替え。default / blue / green / pink の4つがあり、**default が正**。他は色替えであって、別デザインではない。
_避ける_: カラースキーム、モード(「モード」はダークテーマを連想させる。[ダークテーマは持たない](./adr/0003-no-dark-theme.md))

**マーカーライン** (marker-line):
文字の下に引く蛍光ペン風の帯。テーマごとに色が変わる。強調に使う唯一の手段。
_避ける_: ハイライト、アンダーライン

## 同期

**押し出し** (push):
このリポジトリから Claude Design への一方向の反映。逆向きは押し出しと呼ばない。
_避ける_: 同期、sync(双方向に聞こえる)

**プレビュー** (preview):
`docs/design-system/` に置く、1枚で完結する HTML。Claude Design がカードとして表示する。
_避ける_: サンプル、デモ
