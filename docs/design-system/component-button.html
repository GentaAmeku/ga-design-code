ボタン 使うのは3通りだけ shadcn/ui new-york / dark: は削除済み
default — フォームの送信。ページに1つだけ置く強い操作
<Button type="submit" className="mt-10 w-full cursor-pointer">
ghost + icon — ヘッダーのアイコン操作(テーマ切替・GitHub リンク)
<Button variant="ghost" size="icon">{icon}</Button>
outline + sm — テーマ切替メニューの中の色選択
<Button variant="outline" size="sm">

使っていないのは destructive / secondary / link と size=lg。 新しく必要になったら、まず既存の3通りで足りないかを疑う。
