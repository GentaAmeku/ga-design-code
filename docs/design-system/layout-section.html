セクションの骨格 1スクロール = 1セクション / max-w-3xl / 中央寄せ 最も強い制約。破ると別のサイトになる

正しい形

1280 × 800 — セクションは画面ちょうど
375 × 667 — ここが最も厳しい
はみ出し NG
中身が多いと黙って伸びる

幅は1本きり

max-w-3xl(48rem)を中央に寄せ、左右に px-4 を敷く。段組みは持たない。幅を増やしたくなったら、それは中身を削る合図。

高さは画面ちょうど

セクションは min-h-screen flex items-center justify-center。縦にも横にも中央へ寄せる。置ける情報量は画面の高さで決まる。

はみ出しは不具合

実装は min-h-screen(最小値)なので、中身が多ければ黙って伸びる。目視では気づけない。セクションを足したり中身を増やしたら、375×667 で高さを測る。手順は README にある。

並び

見出し → リード(mt-4)→ 本体(mt-16、md 以上は mt-20)。この順を崩さない。リードは省いてよい。

例外は about だけ

about は画像と文章の2カラムで、見出しも左寄せ。ここだけ骨格から外れている。新しい例外を増やさない。
