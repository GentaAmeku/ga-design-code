余白 — 用途で呼ぶ

heading-to-lead1rem / mt-4 — 見出しからリードへ
stack2rem / space-y-8 — 積み重ねの間隔
heading-to-body4rem / mt-16(md: 5rem)— 見出し群から本体へ
group4rem / gap-8 md:gap-16 — 塊と塊のあいだ。md 未満では stack(2rem)まで詰める

group だけが画面幅で変わる。375×667 に4つの塊を積むと 4rem のままでは収まらないため（ADR-0002）。他の余白は幅によらず一定。
