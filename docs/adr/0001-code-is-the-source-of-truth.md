# デザインシステムはコードを正とする

デザインシステムの正はこのリポジトリのコードに置き、Claude Design へは片方向で押し出す。Claude Design 側を正にすると、改修のたびにコードが動いて向こうが古くなり、どちらが本当か分からなくなるため。

## 帰結

- Claude Design で作った案は「見た目の案」として扱い、コードは手で書く。出力された HTML をそのまま移植すると、Tailwind と素の CSS が混ざって後から剥がせなくなる。
- `docs/design-system/` のプレビューは、コードが変わったら追随させる。食い違ったときはコードが勝つ。
- プレビューに書くトークンの値は `src/styles/variables.css` と `src/styles/themes/default.css` から転記する。手で書き写すとここがずれ、プレビュー全体が嘘になる。
