# トップページは1スクロールに1セクション、はみ出しを許さない

トップページの各セクションは1スクロールにちょうど1つ収め、画面の高さからはみ出させない。余白を広く取って一度に一つだけ見せることがこのサイトの性格であり、セクションが伸びるとその性格が崩れるため。

## 帰結

- **1セクションに置ける情報量は、画面の高さで上限が決まる。** 情報を足したくなったら、まず何を削るかを決める。足せないことが制約であって、不具合ではない。
- 実装は `min-h-screen`(最小値)なので、中身が多ければ黙って伸びる。守れているかはブラウザで測らないと分からない。手順は `docs/design-system/README.md` に置く。
- 2026-08 時点で about と skills が 375×667 で違反している(それぞれ +44px、+249px)。skills は4グループを縦に並べる構造そのものが原因で、値の調整では収まらない。修正はデザインの作り直しになるため別作業とした。

## 適用範囲

トップページのセクションに限る。実績詳細やブログのような読ませるページの骨格は、そのコンテンツを作るときに決める。
