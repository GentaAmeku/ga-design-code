## はじめに

日々開発をしていく中で、ClaudeやCodexに何もハーネスを与えない状態でHTML資料を作成していると、後で見返す際に「どこに置いたっけ…」となりがちで探すためにAIに確認したりしていた。そこで今回は「置き場」となる場所を作り、さらにJSON形式で作成することによって、ブラウザでレンダリングできるような仕組みを作成してみました。

https://github.com/GentaAmeku/ai-handout-studio

![AI Handout Studio の編集画面。左にスライドの一覧、中央にキャンバス、右にプロパティ](/images/ai-handout-studio/editor-cover.png)

*エージェントが書いたスライドを、ブラウザで開いたところ。*

## AI が作った資料の課題感

### 1. 資料が散らばる
セッションのプロジェクトが違えばそのフォルダに`HTML`や`PPTX`が生まれ、あとで探しづらい。
全体で確認できるようにプロンプト変えると、ホームの`tmp/`のような場所に作りがち。

### 2. 修正時にトークン消費がかかる
「ここだけ直して」というような指示が多く、資料の確認→修正を繰り返すことで無駄なトークンの消費が生まれてしまう。

### 3. 資料毎の見た目にバラツキがある
特に複数のAIエージェントを横断的に使っている、かつ、デザインシステムを構築していない（ハーネスも作っていない）場合に置きがちで、デザインに統一感がない。

<!-- この3つが、次章の「置き場」「JSON」「テンプレート」にそれぞれ対応する。対応が見えるよう、次章の冒頭で1文で受ける。 -->

## 作ったもの：「置き場」と3区分の資料

AIに全てを任せて作ってもらうより、まず「置き場」を用意してあげて、JSON形式で書き出してもらう。その後はWebUIで見た目の変更や、内容の微調整を行えるようにした。デザインテンプレートもWebUI側で設定できるようにし、レイアウトやフォントサイズも調整可能に。

![資料一覧。エージェントが作った資料がカードで並ぶ](/images/ai-handout-studio/list.jpg)

*どのフォルダの会話から頼んでも、できた資料はここに並ぶ。検索とお気に入りがあり、同じ Wi-Fi のスマートフォンからも開ける。*

## 仕組み：AI は JSON だけ書き、見た目はテンプレート、仕上げは人

### 資料の正本はJSON1つ

![編集画面の JSON タブ。選んでいるスライドの JSON がそのまま見える](/images/ai-handout-studio/editor-json.png)

*スライド1枚は、文章・構造・座標だけの JSON。色や class は書かない。*

### 見た目はテンプレートが持つ

![スライドのテンプレート一覧。同じ中身の見本が、テンプレートごとに違う見た目で並ぶ](/images/ai-handout-studio/templates.png)

*中身は同じで、見た目だけが違う。tokens.json から CSS を生成し、色の直書きは build が止める。*

### 仕上げは人がブラウザでやる

![本文スライドで見出しブロックを選び、右のプロパティで位置・大きさ・文言を直している](/images/ai-handout-studio/editor-selected.png)

*選択・移動・リサイズ・挿入・削除・テキスト編集は、画面で人がやる。描画後にはみ出しを測るので、AI の座標の見積もりが外れても気づける。*

![編集画面の上部にある PNG・HTML・PPTX・PDF の書き出しボタン](/images/ai-handout-studio/export-bar.png)

## 質問票：作る前にエージェントが聞いてくる

<!--
小見出しなしで、段落4つ。
1. なぜ聞かせるか: 推測で作られた資料の直しが一番高い。Claude Code の AskUserQuestion は1問ずつには速いが、比較表・図・根拠を見ながら数問まとめて答えるには狭い。Codex でも同じ形で聞きたかった。線引きは「1〜2件の即答は会話、読み比べが要るときは質問票」。
2. 質問は JSON、見た目はテンプレート。質問ごとに「何を比べて決めるか」を持つ(下の画像)。
3. 回答は「回答をコピー」で Markdown になり、会話へ貼るとエージェントが続きを進める。回答サーバーを立てない理由(URL 1本、待つプロセス無し)。Thariq Shihipar(Anthropic)の 2026-05-20 の記事「The Unreasonable Effectiveness of HTML」の「UI の最後は copy as prompt で貼り戻す」と同じ型、と1文(先後は言わない)。
4. 貼られた回答は同じ資料に残るので、あとから開くと答えた状態で出る。決めたことの記録になる。この記事の方針も質問票で決めた。
-->

![回答済みの質問票。本文の下に比較表と情報の枠、その下に選択肢と回答文の欄](/images/ai-handout-studio/sheet-answered.png)

*質問ごとに「何を比べて決めるか」を持たせる。比較表・図・注意は本文の下、回答欄はその下。*

![最後の質問の画面。次へ進むボタンの位置に「回答をコピー」がある](/images/ai-handout-studio/sheet-copy.png)

*答え終わると「回答をコピー」が出る。Markdown になった回答を会話へ貼ると、エージェントが続きを進める。*
